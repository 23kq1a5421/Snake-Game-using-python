# 🐍 Snake Game Using Python

## 📌 Project Description
Snake Game is a simple and interactive console-free game application developed using Python's Turtle Graphics module. The player controls a snake using keyboard arrow keys, collects food, and increases the snake's length while earning points.

The game includes collision detection, score tracking, high-score tracking, and gradually increasing speed to make the gameplay more challenging.

## 🎯 Features
- **Keyboard Controls:** Control the snake using the arrow keys (Up, Down, Left, Right).
- **Food Collection:** The snake grows whenever it eats food.
- **Score Tracking:** Earn 10 points for every food item collected.
- **High Score:** Maintains the highest score achieved during the game session.
- **Collision Detection:** Detects collisions with walls and the snake's own body.
- **Increasing Difficulty:** Snake speed increases gradually as the score increases.
- **Sound Effects:** Plays different sounds for food collection and collisions.

## 🛠️ Technologies Used
- Python
- Turtle Graphics
- Random Module
- Time Module
- Winsound Module

## 💻 Requirements
- Python 3.x
- Windows Operating System (for Winsound audio effects)

The Turtle, Random, and Time modules are included with Python. No additional package installation is required.

## 🚀 How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone <your-repository-link>
```

**Step 2:** Navigate to the project folder.

```bash
cd Snake-Game
```

**Step 3:** Run the Python file.

```bash
python snake_game.py
```

**Step 4:** The game window will open. Use the arrow keys to control the snake.

## 🎮 Game Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |

## 🕹️ How to Play
1. Start the game by running the Python file.
2. Use the arrow keys to control the snake.
3. Move the snake towards the food.
4. Each time the snake eats food, its length increases and your score increases by 10 points.
5. Avoid hitting the walls or the snake's own body.
6. Try to achieve the highest possible score!
